认证源接入与生效全流程

从新增一个外部身份来源，到它真正出现在登录页可用的全过程：连接参数 → 连通性验证 → 字段映射 → 账号同步 → 启用与呈现。每一步的输入产出、失败码与回退口径。

认证源是「用户从哪来」的落笔处。一个源从新增到真正可用，要跨过连接参数、连通性、字段映射、账号同步、启用与呈现五道关；任一道未过，源都停在「已停用」且不在登录页出现。

1 主干步骤

新增认证源配连接参数连通性测试字段映射立即同步配认证方式启用登录页呈现
「启用」是唯一让源对用户可见的动作。新建的源默认已停用 —— 必须先完成连接参数与连通性测试，才能启用。
1
新增认证源安全管理员

填写展示名称、类型（本地账号体系 / AD·LDAP / OIDC / CA）、来源标注。提交后源以 已停用 落地，不生成任何外部连接。

2
配置连接参数安全管理员

按类型给不同字段组：AD·LDAP 填目录地址 / Base DN / Bind DN / Bind 口令 / TLS 与证书校验；OIDC 填 Issuer / Client ID / Client Secret / 回调地址 / Scope；CA 填信任根与 CRL 拉取周期。口令与密钥加密存储、界面不回显明文。

3
连通性测试平台 → 外部目录

AD·LDAP：向目录地址发起 TLS 握手并用 Bind DN 做一次只读绑定；OIDC：拉取发现文档与 JWKS 并校验签名算法；CA：校验信任根链并试拉一次 CRL。测试使用只读凭据、不写入数据，结果入审计。

4
编辑字段映射安全管理员

把平台字段（账号名 / 姓名 / 部门 / 邮箱）映射到外部来源属性，如 sAMAccountName、preferred_username。账号名必填；未映射的字段留空，不猜默认值。

5
立即同步 / 配置同步周期平台 → 外部目录

AD·LDAP 走定时增量（默认 30 分钟），范围限定在指定 OU 子树；OIDC 走登录时按需映射，不建全量副本；CA 仅按证书主体按需建映射。

6
为该源配置认证方式安全管理员

从认证方式字典引用方式（本页不能自造方式名），并联合判定每条记录的级别与适用范围；「无端支持」是该条记录上的适用性声明 —— 无端接入的判定与执行由无端网关承载，本页仅声明该方式是否适用于无端（浏览器）接入。

7
启用认证源安全管理员

置为已启用。启用后该源才进入登录页候选集合；未启用的源不在登录页展示。

8
登录页呈现门户

按「展示顺序 + 启用状态」渲染可选源。用户选定后，凭据校验交该源对应的方式链执行。

分支与失败
连接参数缺失或格式非法拒绝启用；源停在「已停用」，不发起外部连接
连通性测试未通过（握手失败 / 绑定被拒 / JWKS 拉取失败）拒绝启用；提示按失败环节定位，不降级为明文连接
账号名映射为空保存被拒；账号名必填，其余字段可留空表示不映射
同步中属性冲突（外部值 ≠ 内部手工账号）告警而非覆盖；仅管理来源标注为本源的账号
同步时外部目录不可达本次同步标记失败并告警；已同步账号保持原状，不影响既有登录
源已启用但被停用停用后不在登录页展示；已使用该源登录的会话按会话有效期自然到期

类型字段是否必填说明
AD / LDAP目录地址 + 端口必填如 ldaps://ad.baize.internal:636，可配主备各一
AD / LDAPBase DN必填如 DC=baize,DC=internal
AD / LDAPBind DN + 口令必填服务账号；口令加密存储、不回显；仅授予只读查询权限

3 状态机与可见性

源状态是否发起外部连接是否在登录页展示可执行的下一步
已停用（新建）否否配连接参数 → 连通性测试 → 启用
已停用（手工停用）否否重新启用（参数保留）
已启用是（按同步周期）是停用 / 改参数（改后须重测）
「展示顺序」与「启用状态」共同决定登录页呈现。顺序只影响排列，不改变任何源的可达性判断。
依据：认证源页（连接参数 / 同步与映射 / 认证方式三段）；认证方式字典页（方式名唯一取值域）　方式名只能引用、不能自造

4 认证方式字典与档位的口径

  • 字典是方式名的唯一取值域：各源支持的方式只能从字典引用，不能自造；被任一认证源引用的方式不可删除，内置方式亦不可删除（运行时自建的方式在未被引用时可删）。
  • 「参考默认级别」不是该方式的安全级别：它只是新建「源 × 方式」记录时的参考初值，不作裁决依据。实际生效的级别挂在「认证源 × 认证方式」上 —— 同一方式在不同源下级别可以不同（如本地账号体系的账号密码 vs 外部 IdP 的账号密码）。
  • 档位不是方式的归属容器：方式与档位之间没有固定映射，平台不列「哪一档由哪些方式构成」；实际级别由「认证源 × 认证方式」联合判定。
  • 一期会话强度上限为 L2（不提供调高入口），L3~L5 方式在二期承载；档位本身不提供删除能力，档位名称与判定含义由平台内置、页面只读。
  • 抗钓鱼由源绑定派生、不单独设列与开关：源绑定是方式的固有属性（凭据在协议层绑定源，钓鱼站点拿不到有效断言）。具备源绑定能力的方式即抗钓鱼，不具备的无法靠任何配置变得抗钓鱼。「人机校验」不进字典、不占任何档位、不计入会话档位。
  • 「交互式」与「计入会话档位」同属方式的固有属性，登记后随方式生效；非交互式方式不适用于「二次认证」等需人工确认的场景。
